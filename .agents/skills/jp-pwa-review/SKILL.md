# 日语 PWA 审查

只在用户要求审查时使用。读取 AGENTS、当前差异和涉及的需求／设计，不强制全仓扫描。默认只读，用户另要求修复时才修改。

## 关注点

1. 课程 ID 是否稳定；重复导入是否新增重复条目；异常是否部分写入；内容修订是否清空进度。
2. 实际原说法与反推错误示例是否混淆；推荐答案是否误用原错误或句型标题；待确认卡是否进入默认复习。
3. event_id 重试是否重复计数；数据库事务和锁是否避免并发评分覆盖；客户端是否先删队列再等回执。
4. UTC 保存与 Asia/Tokyo 日界线、复习阶段、新卡额度是否符合 DATA_RULES。
5. 原始 HTML、文件路径、数据库凭据是否暴露；接口输入与公开响应是否明确校验。
6. 手机的长文本、翻面评分、断网与同步提示、未完成答案、重复点击是否正常。

给出有证据的实际问题，包含触发条件、影响和精确文件位置。不要将猜测写成发现；不提交纯风格偏好。区分“未实施的设计”与“已实施代码缺陷”。没有发现也说明审查范围及未验证项，不声称全面无缺陷。
