# 聊天 → 生活摘录 → 日语手帖

## 最简单的用法

在能访问本项目的聊天里直接说：

> 加入生活摘录：今天同事说了……，当时的场景是……。帮我解释并给例句。

也可以明确调用 `$jp-life-memo`。不需要输入 JSON 或完整模板。若只想问含义而不收录，直接提问即可。

流程：整理日语与中文说明 → 按日期保存 Memo/JSON → 校验 → Mac 文件事件自动导入 → 应用接收更新。课程页有“全部／课堂／生活摘录”筛选，生活记录不占课堂编号。

## 数据和同步

使用现有 lessons 格式，lesson.tags 包含“生活摘录”。Memo 仍分表达方式与单词。场景、语气、补充例句与待确认项保留；不确定用法可阅读但不进入复习。修订保留稳定 ID，复习历史独立存储。

Mac 应用服务运行时自动监听 lesson.json 与 memo.md。连续保存会合并；文件稳定后校验导入。格式错误不会覆盖已有内容，并在应用显示提示。删除源目录不自动删除数据库内容。手动“更新课程”仍可使用。

已下载记录联网时自动检查版本，在应用打开、回到前台、恢复连接以及收到服务端更新通知时刷新。未下载记录不会自动下载。背诵中途保持本次队列，待同步答题不被内容更新清理。HTTP 下可在线更新，但离线重新启动仍需 HTTPS 的 Service Worker。

应用内没有 AI 自动整理接口；整理在已授权访问项目的 Codex 聊天里完成，没有新增模型 API 费用。

## 手机怎么继续这个聊天

本机“日语学习”是 local 项目，当前聊天是本机 Codex 任务“转写日语课堂并整理复习 memo”。它不是“个人日常app”那种 ChatGPT 项目；普通手机项目列表因此可能只显示后者。

官方流程：电脑桌面应用设置 → Connections → Control this Mac → Set up/Add → 手机扫码，同一账号与工作区批准连接。手机在 Codex（有的版本仍叫 Remote）入口选择这台 Mac，再继续已有任务。保持 Mac 在线、唤醒。可用性取决于版本、功能开放与工作区设置。

不要仅在普通 ChatGPT 聊天中新建同名项目，就认为它能写入这台 Mac 的文件。Tailscale 用于访问日语手帖，Codex Remote 的连接配对是另一件事。

参考：[Codex on mobile](https://learn.chatgpt.com/docs/mobile)、[Remote connections](https://learn.chatgpt.com/docs/remote-connections)。本项目未替你开启远程控制或配对手机。
