# 页面设计与交互

状态：已实现，采用 History 路由及列表内展开详情；设备安装待真机试用。需求映射 R01–R08；示意数字不是实际学习进度。[视觉](VISUAL_SYSTEM.md)、[API](API.md)。

## 页面与路由

| ID | 路由 | 页面 | 主要接口 |
|---|---|---|---|
| S01 | /today | 今日复习（默认首页） | GET /api/v1/home |
| S02 | /lessons | 课程列表 | GET /api/v1/lessons |
| S03 | /lesson/:lessonId | 课程详情 | GET /api/v1/lessons/:id |
| S04 | /library | 词库与表达库 | GET /api/v1/items |
| S05 | 列表内展开 | 条目详情 | GET /api/v1/items/:type/:id |
| S06 | /review | 背诵会话 | POST /api/v1/review/queue；POST /api/v1/review/events |
| S07 | /settings | 设置与同步状态 | GET/PUT /api/v1/settings |

## S01 今日复习

顶栏“今日复习”、本地日期及设置入口。主卡展示当前到期数量、可分配新卡数、主按钮“开始复习”，下面是本日完成评分数和最近课程。

首次数据为空显示“还没有课程”，引导去课程页更新。没有到期卡且新卡额度已用完显示“今天的复习已完成”，可浏览课程，不虚构进度百分比。最近课程显示52表达/106词条等来自API的实时计数。离线显示最后同步时间和本机待同步数。

## S02 课程列表

课程卡包含名称、日期、条目数量和下载状态。右上“更新课程”调用导入接口；完成后刷新，有失败时展示哪课需要处理。用户可“下载离线内容”，显式缓存该课的 JSON DTO 和 Memo。

服务器暂不可达时保留已缓存列表，更新课程不可用并说明原因；不把断网误报成课程被删除。

## S03 课程详情

标题和日期，分段选择“表达方式／单词”，各自搜索。表达卡显示推荐日语、中文、标签与收藏，展开后显示原说法（若有）、反推错误示例（若有）、规则和课堂／补充例句。单词卡显示日语、假名、词性和中文，展开搭配、例句。

原说法和反推示例分开存、分开显示；「伝えば」为已确认原说法。推荐答案必须是「伝えれば」，不能显示数据标题“動詞のば形”来代替答案。现有 JSON 中部分标题为句型总称，已通过数据适配补齐 corrected_japanese，见 LESSON_FORMAT。

待确认标签不阻止阅读，但“加入复习”不可用。页面提供“复习本课”和“下载这一课”，后者显示缓存成功/失败及更新时间。

## S04/S05 词库与条目

顶部搜索，类型、主题、收藏筛选；默认跨所有课堂和生活来源搜索，按课程查看由收集站提供。列表触底追加加载，每批20条，滚动保留搜索条件。词条跨课不重复显示，详情列出课程来源和本课例句。

搜索支持日语、假名、中文，第一版大小写与 Unicode NFKC 规范化，不做自动翻译或模糊 AI 检索。离线搜索仅针对本机已下载课程，明确提示范围。

收藏在线修改，离线仍可读已缓存收藏；详情返回后保留列表位置。没有结果显示“没有找到相关内容”，提供清除筛选。

## S06 背诵

进入时选择卡型（全部／单词／表达／纠错）和课程范围；在线获取队列，离线从已缓存队列继续。新卡需先在线分配每日额度，完全离线首次不自行追加新卡。

题面：单词→回想读音/意思；表达→中文意图；纠错→原错误或明确标记的反推错误。底部“查看答案”，未翻面不显示评分按钮。答案展现正确日语、解释与例句，来源可点到课程详情。

评分“忘了／有点印象／记住了”；一次点击后锁按钮，先可靠保存本机事件再切下一张，在线尽快提交。同步失败不撤销已保存答案，保留待同步提示，不能无限转圈挡住离线答题。

顶部进度为本次队列位置，不等于掌握率；退出可继续待完成队列。队列结束显示本次评分数与待同步数。忘记卡10分钟后到期，不立即反复塞进同一队列制造无法结束的练习。

## S07 设置

每日新卡上限，默认10，范围0–100；时区第一版固定Asia/Tokyo。展示服务连接、课程导入结果、已下载课、缓存时间和待同步状态。

“同步答案”可重试；清理课程缓存前检查是否有未同步事件，不删除答题队列。数据库备份第一版按文档操作，不在页面提供恢复正式库按钮。安装提示按浏览器能力显示，iOS说明添加到主屏幕，不能保证所有浏览器弹出同一安装按钮。

## 统一状态

API错误转中文可理解信息；长内容可滚动但评分按钮不遮挡正文，适配安全区域。空数据、加载、失败、离线、待确认、缓存过期分别展示。保留键盘焦点和减少动态效果支持。

## History 路由返回规则

开发时由 Vite 提供页面入口回退；生产时由 Fastify 返回 apps/web/dist 中的文件，非 API 页面路径回退 index.html，API 不存在仍返回 JSON 404。旧的 /#/ 链接在前端启动时转换为对应的 History 地址。

## 学什么语品牌更新

产品名已定为“学什么语”，首页、导航、查找和设置使用轻松中文。首页“今天也整两句”，收集页“都是在哪学的？”，查找页“这句咋说？”。评分三项及错误来源标签保持准确。新视觉与图标见 VISUAL_SYSTEM。

学习条目按主题相邻展示。展开原句时先显示“场景与表达意图”；所有卡片中的主题按钮通过应用内部状态打开相关表达面板，跨课堂和生活来源聚合；不修改页面路由、搜索与收藏条件，主题不写入 URL。来源链接继续保留。

查表达列表采用触底追加加载，不显示页码或上一页／下一页。修改搜索、卡型、收藏或主题时从头加载；在线失败可用已下载内容继续，加载失败保留已有条目并给重试入口。

切换类型、主题、标签、课程或收藏筛选时，立即展示与卡片布局一致的骨架屏，覆盖搜索防抖等待与请求时间；筛选控件保留可操作。空结果仅在加载完成后显示。触底追加仍保留已有卡片，以列表底部提示加载状态。骨架屏提供读屏加载提示，尊重系统减少动态效果设置。

卡片详情展开与收起使用高度及透明度过渡，结束后恢复自动高度，长解释可完整显示；系统减少动态效果时立即展开。浏览器刷新回到 /today 首页，主题筛选为内存状态；未完成复习与离线待同步答题继续保留。直接打开课程或复习网址仍可访问对应页面。

查表达页不提供课程筛选或额外筛选抽屉。课程查看、课内搜索、下载与本课复习统一在收集站；主题选择默认显示“全部主题”。

查表达筛选栏使用固定比例布局，下拉框宽度不随选项文字或加载状态变化。等待新结果时保留主题选项与当前选择；旧服务缺少完整主题目录字段时沿用已获取选项。

单词音调：可选 pitch_accent 随课程详情、条目和复习答案 DTO 传递，来源 JSON 中保存，无独立 SQL 列。词卡假名旁仅显示东京式编号（⓪、①、②等），不附类型名称；展开可查看拍数说明、来源与多种读法备注。未核实不显示编号；离线下载保留已核实数据，旧缓存可正常读取。

复习答案中的“看相关表达”打开底部参考面板，保持路由、答案展开状态、当前卡片及评分队列。关闭按钮、点击遮罩或 Escape 关闭后仍在原答案并恢复焦点与滚动；背景评分不可操作。面板可继续展开相关卡片、切换关联主题、分批查看及重试；离线使用已下载内容。查表达和课程阅读页也采用相同弹层，关闭后保留原页面、搜索条件与展开卡片。普通紫色标签使用垂直居中文字，与关联按钮对齐。

关联面板支持逐层打开：在面板里点击关联主题新增一层，关闭最上层回到上一层并保留展开内容与滚动；最后一层关闭回到原页面。

面板中点击当前相同主题时不重复打开，只显示“已经在看这个主题啦”的短暂气泡；点击不同主题仍新增一层。

复习进度：首页主卡突出已领取待完成张数与“继续复习”。复习页顶部固定显示剩余张数、本次完成数和进度条；只评分后减少，查看答案和相关面板不推进。初始总数保存在本机队列 initial_count，随离线答题原子保存并支持恢复；旧队列无法还原此前总数，以第一次恢复时的剩余数量为基准，不混用今日累计完成数。离线首页使用本机队列剩余数量。页面图标和首页主卡分别显示准备、思考、完成的表情，开心沿用原图标。

再次领取时按钮显示“正在领卡片…”。空队列在按钮旁明确说明无到期/新卡或当前范围无卡；其他范围仍有待完成卡时提供“切换到混合复习”，清空卡型与课程限制后由用户点击重新领取。同步或请求失败也在领取区域显示可读错误，不静默停在完成页。

设置“就这么定了”保存成功后出现短暂气泡，失败也在当前位置反馈。复习队列提供“取消本组”，结束当前领取队列、退回未作答新卡并显示提示，已作答进度保留；离线时禁用取消入口并说明需要联网。

手机仅支持竖屏学习：Manifest 声明 portrait-primary。不支持方向锁定的浏览器横屏时显示全屏竖屏提示并阻止操作，转回竖屏恢复原卡片、答案与参考面板，不更改队列。按屏幕方向判断，不因软键盘缩小视口而触发；桌面浏览器不限制横向窗口。
