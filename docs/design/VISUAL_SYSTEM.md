# 视觉设计系统

状态：设计提案，待用户与真机验收。高保真图：[三屏设计稿](assets/mobile-design-board.png)。图中日期、数量和完成比例为演示数据，不硬编码到产品。

## 风格

温暖的纸感学习手帐：奶油背景、森林绿主色、少量朱红强调。图中山水、书本与枝叶仅作轻量装饰，实施时保留可读性和留白，不能让装饰遮挡文本。原图不是可直接运行的页面。

| 变量 | 值 | 用途 |
|---|---|---|
| background | #F8F5ED | 页面背景 |
| surface | #FFFCF6 | 卡片 |
| primary | #244C3A | 主按钮、推荐日语 |
| accent | #C7674D | 原错误提示和局部强调 |
| text | #24352C | 正文 |
| text-muted | #69736A | 次要说明 |
| border | #E2DDD0 | 细边框 |

色值为实施初值，正文实际检查对比度，不能只凭视觉稿判断无障碍。触控目标至少 44px；间距使用 4/8/12/16/24/32，页面边距手机 20px。卡片圆角 18–22px，主按钮 14px，阴影轻而少。

## 字体与布局

正文用系统中文／日文字体，日语元素设置 lang=ja；标题可用本机明朝／衬线字体作为可选回退，正文不依赖下载字体。日语主要内容 24–32px，中文正文16px，次要说明14px，读音18px；允许缩放和长文本换行。

手机基准390px，320px仍可操作；平板约束阅读宽度，不把卡片无限横向拉伸。阅读页保留底部导航，背诵页隐藏主导航减少干扰，但提供退出并保留未同步答案。

卡片和例句尽量不用横向表格，单词详情用分行信息。错误对照可划线，但仍显示“原说法／反推错误示例”标签，不只靠红色或划线传达含义。

## 状态与动画

按钮明确文字，评分三项等触控面积。翻卡采用轻微淡入或短位移，不用大幅旋转；尊重减少动态效果设置。加载使用骨架和可理解提示；离线状态常驻小提示，未同步数量可查看。空状态给下一步操作。
