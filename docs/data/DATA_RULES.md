# 导入、数据与复习规则

本文为 V1 已实现的规则，自动验证记录见 ../development/VERIFICATION.md。结构定义见 [LESSON_FORMAT](LESSON_FORMAT.md)。

## 1. 内容与进度分离

建议实体：Lesson、Expression、Vocabulary、LessonVocabulary（课程来源及本课例句）、Favorite、ReviewCard、ReviewEvent、ReviewState。

- 内容记录以课程 JSON 的稳定 ID 标识，不按当前行号重新生成。
- 卡片身份为 `item_type + item_id + card_type`，数据库建立唯一约束；不要求在源文件中新增卡片 ID。
- 单词日语题面、表达中文题面、纠错题面对应不同卡型；进度按卡型独立。
- 第一版为固定个人用户，客户端不能自由传入用户 ID 指定数据归属。

## 2. 导入

扫描每课 `lesson.json`，读取文件内容后完成 Schema、ID、日期、引用和状态验证，再事务写入。一课失败不部分更新该课。

- 同 ID 同内容：幂等，不创建额外数据。
- 同 ID 修订：更新内容，不更新 ReviewState、不删除 ReviewEvent。
- 相同 vocabulary ID 跨课复用：本课来源和例句保留在关联记录中；词库按 ID 聚合，不重复创建词条。
- 同 vocabulary ID 却出现不兼容词形、读音或义项：该课导入失败，要求人工确认 ID；不静默覆盖。
- 相同表面词但 ID 不同：提示可能重复，不擅自合并进度。
- 修订课不再包含的来源关联标为不活跃；全局条目和历史保留。仍有其他课程来源的词保持可用。
- `needs_review` 条目不生成默认可复习卡；已有进度保留，恢复可信状态后可继续。
- 源课程文件消失：不自动删除课程。V1 不提供不可逆课程删除。

## 3. 卡片内容

单词卡：题面日语，答案读音、词性、中文、搭配与例句。

表达卡：题面中文意图与必要场景，答案推荐日语、解释和例句。

纠错卡：优先采用可靠 `original_japanese`；没有时可用 `error_example_japanese`，明确标为反推错误示例；都没有时不生成。答案依据推荐表达与解释，不能把错误字段当正确答案。

新增内容默认未学习。今日页选择到期卡优先，再安排新卡；每日新卡上限默认 10 张，按 Asia/Tokyo 的日期统计当天首次分配的不同卡片，分配即预留额度，不因页面重载重复分配；未完成卡可继续。完全离线时仅复习已缓存队列，不自行新增额度。

## 4. 默认间隔复习

简单规则先跑通，不采用未经讨论的复杂算法。阶段间隔为 `[1, 3, 7, 14, 30]` 天。

- 忘了：阶段重置为 0，10 分钟后再次到期。
- 有点印象：阶段保持不变，1 天后到期。
- 记住了：按当前阶段取间隔，随后阶段加 1，最多停留在最后阶段。
- 第一张新卡的“记住了”使用 1 天间隔。

间隔以评分时间为基础，天表示 24 小时；今日统计日界线用 Asia/Tokyo。数据库存 UTC。评分和算法版本保存到事件，后续调整算法不改写历史。

## 5. 在线与离线事件

每次评分生成 UUID event_id，包含卡片标识、评分、客户端答题时间、设备标识与算法版本。服务端分配接收顺序并事务保存事件及最新状态。

- event_id 唯一：同事件重试返回成功及已存结果，不重复计数。
- 客户端答题时间用于历史展示；到期计算使用服务端接收时刻，避免设备时间误差使进度回退。
- 同批离线事件按客户端发生顺序提交；跨设备以服务端成功接收顺序为权威顺序。本版不做复杂历史重放或冲突合并。
- 新收到的离线事件会据当前状态继续计算；与设备上的暂定进度可能不同，返回服务器结果后刷新。
- 客户端仅在收到成功回执后删除本地事件。请求超时、断网或服务器失败仍保留，不能因更新 PWA 清掉队列。
- 若卡片暂被停用或内容未导入，返回可理解的状态，本地保留该事件供重试／处理，不能丢弃。

这一策略适合单人设备使用，界面展示同步中、待同步数量及失败提示。

## 6. 备份

同时覆盖 PostgreSQL 与 lessons 源文件。数据库备份包括收藏、事件和状态。备份目录不进入 Git。恢复必须在隔离测试库验证；任何正式库覆盖操作另行明确授权。

## 自动监听与生活来源

fs.watch 递归事件监听；事件后合并500毫秒，并间隔200毫秒核对文件快照。文件持续变化时延后，无事件时不扫描。校验失败保留最后一次有效数据；新增目录和原子替换触发更新，删除源不自动删数据库。监听不可用时明确显示状态，保留手动导入。

生活摘录沿用 schema_version=1，lesson.tags 含生活摘录；真实日期未知则 lesson_date=null。收藏/进度/事件不进入内容 JSON，自动刷新只更新下载副本，不改当前会话及 outbox。

## 学习内容质量与关联整理

- 卡片正文是知识说明，不写“你追问”“老师说”“本课补充”“用户确认”等会议记录口吻。课堂来源、补充来源与确认状态留在结构化字段或来源标识；用法正文直接解释接续、含义、场景与例句。
- 每个实际原说法同时保存 original_context_zh：当时谈什么、想表达什么。依据课堂材料或用户反馈填写；不编造背景。原日语字段只存原句，不把中文解释拼入句子。
- 老师的场景建议保持原意，不擅自加反驳来改写教学重点。明显疑义先查证，无法明确忠实表达时请用户确认，不把场景建议扩张为全部日语的绝对规则。
- 标题提到的每种接续都必须有说明和例句。区别不同词、不同形式时分段，不只列一个名称。补充例外或范围时给具体接续与例句，不留“还有其他用法”一句话。
- 相关知识使用统一“主题：……”标签，课堂和生活来源同样归类。同一主题条目相邻排列；独立用法可以另建条目，保留旧 ID。课程是来源，不是唯一分类方式。今后先查已有主题和条目再归档，避免同义标签分裂。

术语使用自然中文或保留完整日语，不混用日语汉字拼成生硬中文。例如主题使用「気分転換」，中文说明用“换换心情／放松一下”。

主主题按语法功能、表达意图或词义区别分类，不能把谈话背景“工作”当作所有知识点的类别。主题应可复用于未来内容；场景另作辅助标签。敬语卡片同时写措辞礼貌程度与实际要求力度，保留课堂具体行为例子和对象关系，不用“礼貌”抹平强要求感。

分类以卡片实际解释的知识点为准，不依据例句名词或场景命名；例如「ゲームで遊ぶ」归入“で的用法”，具体手段含义在卡片内说明，「本格的です」归入本格与本格的用法。只有语法用法或表达意图确实相近的内容才共用主主题，没有合适的关联时可独立成组，不强行归并。

本项目统一用“で的用法”收纳助词で的地点、手段、时间及での名词修饰，保留各自独立卡片；であれば保留条件分类。巡り词义与兴趣爱好分别分类，不因同一谈话场景合组。

单词音调使用东京式下降点编号，必须核对词形、读音和具体义项，保留词典或 OJAD 来源；未知留空。复用旧 ID 补音调，不改变收藏和复习进度，不将原形音调套用到其他活用。

用户明确点击“取消本组”后，未作答新卡的领取占位退回，释放相应日期配额；已作答卡片的领取记录、评分、复习计划和收藏保留。客户端先同步答题，成功取消后持久保存空队列；离线或同步仍失败时不取消，显示提示。已有到期卡不因取消而算完成。
